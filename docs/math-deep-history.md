# History, equations and deep answers

Open **More → History**, or **Ctrl+Alt+H** while the overlay is visible. This explicitly focuses the Setup window. Search questions or answer text, then select a dated entry. The overlay's **Ctrl+Alt+Left/Right** browses previous/next answers without taking focus; **Ctrl+Alt+L** returns to the live answer.

To keep answers across launches, choose **History → Save answer history locally**, then **Save changes**. Saving is off by default and your existing preference is preserved. The latest 250 question/answer entries are retained in `.data/answers.json` when enabled. Entries are searchable by text and dated; they are not grouped into named assessments. Sessions closed while saving was off cannot be recovered. Screenshots and raw audio are not stored in history. Saved text can contain private context; delete entries in History or use the project's data-cleanup option to remove it.

**F7** requests one Luna answer with **xhigh** reasoning. It uses attached/pending images first (waiting for F10 capture), then a typed or fresh speech question, otherwise reruns the displayed question, including a history question. **More → Deep answer · F7** does the same. It does not change saved reasoning or normal **F11**/**F9** behavior. **F8** still starts/pauses speech. F7 keeps focus elsewhere. Deep answers may take longer and use more billed reasoning tokens; their request uses the Azure model output limit with no app token cap. Xhigh has up to five minutes to start returning text, followed by a 90-second text-stream idle timeout. **Ctrl+Alt+Escape** cancels. An unsupported Azure reasoning setting produces a specific message without silently downgrading.

Programming fences remain syntax colored and selectable, with **Copy code** and **Ctrl+Alt+C** for the first programming block. Backticks, tilde fences and unfinished streamed code are supported. Equations support `$...$`, `$$...$$` on separate lines, `\(...\)`, `\[...\]`, and fenced `math`, `latex` or `tex`. Fractions, sums, roots, superscripts/subscripts and supported matrix/alignment environments render as native scalable drawings. Wide display formulas have a horizontal scrollbar. Font zoom also sizes equations. Unsupported, incomplete or oversized TeX remains readable source; this is a math renderer, not a complete TeX document compiler. Copy/export/history retain original Markdown and LaTeX. No browser, remote assets or separate formula window is used.

Model documentation: https://developers.openai.com/api/docs/models/gpt-6-luna. Azure output budgets and reasoning: https://learn.microsoft.com/azure/foundry/openai/how-to/reasoning#how-reasoning-works.

Luna combines the last three completed pairs with a compact index of earlier current-session exchanges, relevant earlier excerpts and a snapshot of both transcription sources. Normal F11, images, F7, automatic answers and practice feedback share this path. Interrupted, cancelled, superseded, deleted and previously loaded answers are excluded from automatic memory. Explicit selected-history follow-ups include a single reference. Context has labelled input safeguards for very long exchanges; full retained answers stay in History. See session-reliability.md for budgets, session boundaries and checkpoints. Prior answers remain untrusted references rather than evidence of experience or new instructions. Saving stays opt-in.

F6 requests the configured Sol deployment with high reasoning. It shares the same input priority and current-session context as F7 without changing Luna. Configure or test it in Setup → Connection. Bare balanced backslash fractions render without delimiters; inside equations, /frac and /text are repaired and dfrac/tfrac are supported. Use explicit math delimiters for compound expressions. Original copied/exported Markdown is retained.
