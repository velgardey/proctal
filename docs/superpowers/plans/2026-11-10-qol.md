# Proctal Quality of Life Plan

Execute inline using executing-plans and meaningful regressions. The user authorized the full pass and the primary Answer behavior; preserve the existing Windows app, account-protected profile and project-local dependencies.

Goal: Answer/F11 submits typed text or the latest interviewer speech immediately, including partial captions. Screenshot answering is a separate explicit action (Ctrl+Alt+S) which may wait for capture. Improve responsiveness and remove disruptive request/UI state changes.

1. Add failing regressions for text submission during pending capture, partial/final interviewer input and continuation, candidate exclusion, duplicate requests, stable question display during streaming, manual-to-auto suppression, pending-image clearing and cancellable connection controls. Implement controller input/command state and preserve explicit screenshot retry/capture sequencing.
2. Add a meaningful streaming burst regression. Publish first text immediately, subsequent updates at most every 40ms, and flush the final/partial result. Show cloud retry progress. Wire persistent Answer/Stop, explicit Answer images, input hints and shortcuts. Apply opacity/font/wrap/follow changes without resetting geometry or rebuilding unrelated glass/layout. Preserve nonactivation and capture hiding during concurrent text requests.
3. Full suite/cleanup and native checks including real command routing, first-text/final rendering, small layouts and independent images. One fresh read-only review, one regression-backed Important fix pass. Update shortcuts/guide/acceptance, rebuild and verify private-data-free portable/source archives.

Review focus: answer source and item boundaries; late transcription after manual submission; duplicate and superseding requests; cancellation/final text; screenshot-clear races and window restoration; cached request settings; first-launch/short-screen/nonactivation behavior. Real Azure latency/audio/receiver sharing remain manual checks.

Ruling: Separate speech/F11 from screenshots rather than guessing which input the user wants — matches the user's new instruction and prevents image capture/upload from delaying a speech answer. Existing F10/F11 image workflow becomes F10 then Ctrl+Alt+S; make that visible in the app and guide.
